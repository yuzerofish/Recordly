# Recordly Silhouette Agent Guide

This repository is a personal Apple Silicon macOS fork of Recordly with a local black-silhouette webcam effect.

## Working Baseline

- Upstream baseline: `webadderallorg/Recordly@360b1605009b1c9439629bfaf2033c59f94c611b`
- Feature branch: `codex/recordly-silhouette`
- Stack: Electron, React, TypeScript, Vite, Vitest, and MediaPipe Tasks Vision
- License: AGPL-3.0; retain upstream attribution and bundled third-party notices

## Common Commands

- Install: `npm install`
- Develop: `npm run dev`
- Test: `npm test`
- Permission regression: `npx vitest --run src/hooks/useScreenRecorder.test.ts electron/permissionPolicy.test.ts`
- Type-check: `npx tsc --noEmit`
- Package for this machine: `npm run build:mac -- --arm64 --dir`

## Source Boundaries

- Keep shared webcam-effect logic in `src/lib/webcamEffects/`.
- Preview, project playback, MP4, and GIF paths must use the same effect settings and frame timestamps.
- Silhouette mode must fail closed: never reveal or export the raw webcam frame when processing fails.
- Keep MediaPipe models and WASM local under `public/mediapipe/`; never upload webcam frames.
- Keep project compatibility in `src/components/video-editor/projectPersistence.ts`; legacy projects default to the original webcam view.
- Keep macOS permission policy in `electron/permissionPolicy.ts`.
- Keep the personal app identity aligned across `electron-builder.json5`, `build/recordly-personal.requirements`, and `scripts/stabilize-macos-adhoc-identity.mjs`.

## Repository Hygiene

- Do not commit `release/`, `dist/`, `dist-electron/`, `.tmp/`, recordings, saved projects, or installed applications.
- Do not commit native binaries regenerated by the local toolchain unless the change is intentional, source-backed, and reproducible.
- Do not remove or replace `LICENSE.md`, upstream attribution, or files under `public/licenses/`.
- Treat this as an arm64 personal build, not an official Recordly release.
- Push this work only to `fork/codex/recordly-silhouette`; never push the feature branch to upstream `origin` or publish with the current upstream release target.
- For macOS TCC validation, launch an installed app from one stable path rather than changing build paths between runs.

## Current State

The two-state silhouette workflow, local cartoon-face tracking, persistence, shared rendering, permission-loop fix, tests, and arm64 packaging are implemented. See `docs/recordly-silhouette-personal-archive.md` for verified evidence and remaining limitations.
